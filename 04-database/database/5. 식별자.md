## 개요

**식별자(Identifier)**는 엔터티 내에서 각 인스턴스를 **유일하게 구분**할 수 있는 속성(또는 속성의 집합)이다.

실제 DB에서는 주식별자가 **PK(Primary Key)**로 구현된다.

---

## 주식별자의 특징

| 특징 | 설명 |
| --- | --- |
| **유일성** | 주식별자로 모든 인스턴스를 유일하게 구분한다 |
| **최소성** | 유일성을 만족하는 **최소한의 속성**으로 구성한다 |
| **불변성** | 한 번 지정된 값은 **변하지 않아야** 한다 |
| **존재성** | 값이 반드시 있어야 한다 (**NULL 불가**) |

---

## 식별자의 분류

| 기준 | 분류 | 설명 |
| --- | --- | --- |
| **대표성 여부** | 주식별자 | 엔터티를 대표, 다른 엔터티와 참조 관계로 연결 가능 |
| | 보조식별자 | 유일하게 구분은 가능하지만 대표성이 없음, 참조 관계 연결 X |
| **생성 여부** | 내부식별자 | 엔터티 내부에서 스스로 만들어짐 |
| | 외부식별자 | 다른 엔터티와의 관계를 통해 받아온 식별자 (FK) |
| **속성 수** | 단일식별자 | 하나의 속성으로 구성 |
| | 복합식별자 | 두 개 이상의 속성으로 구성 |
| **대체 여부** | 본질식별자 | 업무에 의해 만들어진 식별자 |
| | 인조식별자 | 인위적으로 만든 식별자 (일련번호 등) |

> 본질식별자 vs 인조식별자 자세히 → [[10. 본질식별자 vs 인조식별자]]

```text
사원 엔터티
  사번         → 주식별자, 내부식별자, 단일식별자
  주민등록번호  → 보조식별자 (유일하지만 대표성 X)
  부서번호      → 외부식별자 (부서에서 받아옴)
```

---

## 주식별자 도출 기준

- 해당 업무에서 **자주 사용되는 속성**을 주식별자로 지정한다.
- **명칭, 내역** 등 이름으로 기술되는 것은 피한다 (변경·중복 가능성).
- 복합으로 구성할 때 **너무 많은 속성**이 포함되지 않게 한다 (→ 인조식별자 고려).

---

## 식별 관계 vs 비식별 관계

부모 엔터티의 주식별자를 자식 엔터티가 **어떻게 상속받는지**에 따른 구분이다.

| 구분 | 식별 관계 | 비식별 관계 |
| --- | --- | --- |
| 상속 위치 | 부모 PK가 자식의 **PK 일부** | 부모 PK가 자식의 **일반 속성** |
| 표기 (IE) | **실선** | **점선** |
| 연결 강도 | 강한 연결 | 약한 연결 |
| 부모 없는 자식 | 불가 | 가능 (FK NULL 허용 시) |

```text
식별 관계                         비식별 관계

주문                             부서
 PK 주문번호                       PK 부서번호
  │ (실선)                          ┆ (점선)
주문상세                          사원
 PK 주문번호 (FK)                  PK 사번
 PK 상품번호                          부서번호 (FK)
```

### 비식별 관계로 설정을 고려하는 경우

- 부모 없이 자식이 먼저 생성될 수 있는 경우
- 부모와 자식의 **생명주기**가 다른 경우 (부모가 삭제돼도 자식은 남아야 함)
- 여러 엔터티가 하나의 엔터티로 통합되어 표현되었는데 각각 별도 관계를 가질 때
- 자식 엔터티에 **별도의 주식별자**를 두는 것이 유리할 때

### 장단점

- **식별 관계만** 사용 → 자식으로 내려갈수록 PK 속성이 계속 늘어나 SQL 조인 조건이 복잡해진다.
- **비식별 관계만** 사용 → 부모 정보를 얻기 위해 **조인이 많아져** 성능이 저하될 수 있다.

---

## 시험 포인트

- 주식별자 특징: **유일성, 최소성, 불변성, 존재성**
- 보조식별자는 **참조 관계 연결 불가**
- 외부식별자 = 다른 엔터티에서 받아온 식별자 = FK
- 식별 관계 = 자식 **PK에 포함, 실선** / 비식별 관계 = **일반 속성, 점선**
- 생명주기가 다르면 → 비식별 관계
- 명칭·내역은 주식별자로 부적합
