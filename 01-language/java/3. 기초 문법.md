## 개요

자바의 기초 문법인 **변수, 연산자, 조건문·반복문, 배열**을 한 번에 정리한다.

다른 언어와 비슷한 부분은 짧게 넘어가고, 자바에서 특히 헷갈리는 부분(형변환, 정수 연산, `==` vs `equals`, 배열 참조)을 중심으로 본다.

---

# 1. 변수

## 변수란?

**변수(Variable)**는 **하나의 값을 저장할 수 있는 메모리 공간**이다.

- 변수를 선언하면 메모리의 빈 공간에 **변수 타입에 맞는 크기**의 저장 공간이 확보된다.
- 이 공간에 값을 읽고 쓰는 것은 **변수 이름**을 통해 한다.
- 같은 범위 안에 **같은 이름의 변수가 있으면 안 된다.**

```text
int age = 15;
 │    │     │
 │    │     └── 저장할 값 (리터럴)
 │    └──────── 변수 이름: 저장 공간에 붙인 이름
 └───────────── 변수 타입: 어떤 종류의 값을 담을지 (그릇의 종류)
```

---

## 선언과 초기화

```java
int age;          // 선언
age = 15;         // 초기화 ('=' 는 오른쪽 값을 왼쪽에 저장하라는 뜻)
int year = 2024;  // 선언과 동시에 초기화

int a, b;         // 타입이 같으면 콤마로 여러 개 선언 가능
int x = 0, y = 1;
```

- **지역변수는 사용하기 전에 반드시 초기화**해야 한다. 초기화하지 않고 사용하면 **컴파일 에러**.
  - 메모리는 여러 프로그램이 공유하는 자원이라, 이전 프로그램이 남긴 알 수 없는 값이 있을 수 있기 때문이다.
- 클래스의 멤버변수(인스턴스 변수, 클래스 변수)는 초기화하지 않아도 **기본값(0, false, null 등)**으로 자동 초기화된다. (→ 객체지향에서 다시)

---

## 명명 규칙

### 반드시 지켜야 하는 규칙

1. **대소문자를 구분**하며 길이 제한이 없다. (`True` 와 `true` 는 다르다)
2. **예약어**를 사용하면 안 된다.
3. **숫자로 시작**하면 안 된다.
4. 특수문자는 **`_` 와 `$`** 만 허용한다.

> 예약어 예: `class`, `int`, `if`, `for`, `new`, `public`, `static`, `final`, `return`, `this`, `super`, `try`, `catch`, `enum`, `interface` ...
> `goto`, `const` 는 예약만 되어 있고 사용하지 않는다. `_` 단독은 Java 9부터 변수명으로 사용 불가.

### 권장 규칙

| 대상 | 규칙 | 예 |
| --- | --- | --- |
| 클래스 | 첫 글자 **대문자** | `Car`, `HashMap` |
| 변수, 메서드 | 첫 글자 소문자, 이후 단어 첫 글자 대문자 (camelCase) | `maxSpeed`, `getName()` |
| 상수 | **모두 대문자**, 단어는 `_` 로 구분 | `MAX_SPEED` |

- 이름은 짧은 것보다 **용도를 알 수 있는 의미 있는 이름**이 바람직하다.

---

## 변수의 타입: 기본형과 참조형

| 구분 | 저장하는 것 | 종류 |
| --- | --- | --- |
| **기본형 (Primitive)** | **실제 값** | `boolean`, `char`, `byte`, `short`, `int`, `long`, `float`, `double` (8개) |
| **참조형 (Reference)** | 값이 저장된 곳의 **주소** | 기본형 8개를 제외한 나머지 전부 (String, 배열, 클래스 ...) |

- 자바는 C언어와 달리 **참조형 변수끼리 연산할 수 없다.** 실제 연산에 쓰이는 것은 모두 기본형이다.

```text
int  n = 10;               String s = "Java";

 n                          s                    (메모리 어딘가)
┌──────┐                  ┌──────────┐          ┌────────┐
│  10  │                  │ 0x100    │ ───────▶ │ "Java" │
└──────┘                  └──────────┘          └────────┘
  실제 값                    주소                    객체
```

### 기본형 8가지

| 종류 | 타입 | 크기 | 범위 · 특징 |
| --- | --- | --- | --- |
| 논리형 | `boolean` | 1 byte | `true` / `false`. 다른 기본형과 **연산·형변환 불가** |
| 문자형 | `char` | 2 byte | 문자 하나. 내부적으로 **유니코드 정수**(0 ~ 65535)로 저장 → 정수와 연산 가능 |
| 정수형 | `byte` | 1 byte | -128 ~ 127. 이진 데이터 다룰 때 |
| | `short` | 2 byte | -32,768 ~ 32,767. C언어 호환용 |
| | **`int`** | 4 byte | 약 ±21억 (-2³¹ ~ 2³¹-1). **정수 기본 타입** |
| | `long` | 8 byte | 약 ±922경. int 범위를 넘을 때 |
| 실수형 | `float` | 4 byte | 정밀도 약 7자리 |
| | **`double`** | 8 byte | 정밀도 약 15자리. **실수 기본 타입** |

- 정수는 보통 **`int`** 를 쓴다. CPU가 가장 효율적으로 처리하는 크기이기 때문이다.
- 실행 효율보다 **메모리 절약**이 중요할 때만 `byte`, `short` 를 쓴다.
- 실수는 정밀도가 높은 **`double`** 을 주로 쓴다.

## 상수와 리터럴

| 용어 | 의미 | 예 |
| --- | --- | --- |
| **변수** | 하나의 값을 저장하는 공간 | `int year` |
| **상수** | 값을 **한 번만** 저장할 수 있는 공간. `final` 을 붙인다 | `final int MAX_SPEED = 10;` |
| **리터럴** | **그 자체로 값**인 것 | `10`, `3.14`, `'A'`, `"Java"` |

### 상수가 필요한 이유

```java
// 숫자만 보면 무슨 의미인지 알기 어렵다
int triangleArea  = (20 * 10) / 2;
int rectangleArea = 20 * 10;

// 상수로 이름을 붙이면 의미가 명확해지고, 값이 바뀌어도 한 곳만 고치면 된다
final int WIDTH  = 20;
final int HEIGHT = 10;
int triangleArea  = (WIDTH * HEIGHT) / 2;
int rectangleArea = WIDTH * HEIGHT;
```

### 리터럴의 타입과 접미사

| 타입 | 접미사 | 예 |
| --- | --- | --- |
| `int` | 없음 (정수 리터럴 기본) | `100` |
| `long` | `L` 또는 `l` | `100L` |
| `double` | `d` 또는 `D` (생략 가능, 실수 리터럴 기본) | `3.14`, `3.14d` |
| `float` | `f` 또는 `F` (**생략 불가**) | `3.14f` |

- `byte`, `short` 는 별도의 리터럴이 없다. `int` 리터럴을 범위 안에서 저장한다.

```java
int octNum = 010;        // 8진수: 접두사 0  → 8
int hexNum = 0x10;       // 16진수: 접두사 0x → 16
int binNum = 0b10;       // 2진수: 접두사 0b → 2

long big = 100_000_000_000L;   // JDK 7+ 숫자 중간에 _ 구분자 사용 가능
```

### 문자 리터럴 vs 문자열 리터럴

| 구분 | 표기 | 규칙 |
| --- | --- | --- |
| 문자 리터럴 (`char`) | `'A'` 작은따옴표 | 반드시 **문자 하나**. `''` 는 에러 |
| 문자열 리터럴 (`String`) | `"AB"` 큰따옴표 | 빈 문자열 `""` **허용** |

- `String` 은 클래스라 `new String("Java")` 로도 만들 수 있다.

## 타입 불일치와 형변환

### 자동 형변환 (작은 타입 → 큰 타입)

저장 범위가 **넓은 타입에 좁은 타입의 값을 저장**하는 것은 허용된다. 값 손실이 없기 때문이다.

```text
byte → short → int → long → float → double
         char ↗
```

```java
int    i = 'A';     // 'A' 의 유니코드 65 가 저장된다
long   l = 123;     // int → long
double d = 3.14f;   // float → double
float  f = 100L;    // long(8 byte) → float(4 byte)도 가능: float 의 표현 범위가 더 넓다
```

### 컴파일 에러가 나는 경우

```java
int   i = 0x123456789;  // int 범위를 넘는 리터럴
float f = 3.14;         // 3.14 는 double 리터럴 → float 보다 넓다. 3.14f 로 써야 함
```

### 명시적 형변환 (큰 타입 → 작은 타입)

`(타입)` 을 붙여 강제로 바꾼다. **값 손실**이 생길 수 있다.

```java
int  n = (int) 3.99;     // 3   (소수점 버림, 반올림 X)
byte b = (byte) 300;     // 44  (범위를 넘으면 앞 비트가 잘림)
byte c = (byte) 128;     // -128 (오버플로우)
char ch = (char) 66;     // 'B'
```

## 지역변수 타입 추론 (`var`)

**Java 10+**: 지역변수(메서드 안에서 선언한 변수)는 `var` 로 타입을 생략할 수 있다. 컴파일러가 오른쪽 값을 보고 타입을 정한다.

```java
var year = 2024;                    // int 로 추론
var map  = new LinkedHashMap<String, Integer>();   // 긴 타입 이름을 줄여 코드가 간결
```

- 초기값이 없거나 `null` 을 대입하면 **추론할 수 없어 에러**.
- 멤버변수, 메서드 매개변수, 반환 타입에는 쓸 수 없다.
- 타입이 정해진 뒤에는 바꿀 수 없다 (`var` 는 동적 타입이 아니다).

```java
var x;          // 에러: 초기값 없음
var y = null;   // 에러: 타입 추론 불가
```

# 2. 연산자

## 연산자 우선순위

```text
높음  ┌ 단항        ++  --  +  -  !  ~  (타입)
      │ 산술        *  /  %   >   +  -
      │ 시프트      <<  >>  >>>
      │ 비교        <  >  <=  >=  instanceof   >   ==  !=
      │ 비트·논리   &   >   ^   >   |   >   &&   >   ||
      │ 삼항        ? :
낮음  └ 대입        =  +=  -=  *=  ...
```

- 헷갈리면 **괄호**로 명시한다.
- 단항, 대입 연산자만 **오른쪽 → 왼쪽**으로 계산하고 나머지는 왼쪽 → 오른쪽.

---

## 산술 연산자와 산술 변환

이항 연산 전에 두 피연산자의 타입을 맞추는 **산술 변환**이 일어난다.

1. **`int` 보다 작은 타입(byte, short, char)은 `int` 로** 변환한다.
2. 두 피연산자 중 **더 큰 타입으로** 맞춘다.

```java
byte a = 10, b = 20;
byte c = a + b;          // 에러: a + b 의 결과는 int
byte c = (byte)(a + b);  // OK

int    i = 10 / 4;       // 2    (정수 / 정수 = 정수, 소수점 버림)
double d = 10 / 4;       // 2.0  (이미 2 로 계산된 뒤 double 로 저장)
double e = 10 / 4.0;     // 2.5  (한쪽이 double → double 연산)
```

### 0으로 나누기

| 연산 | 결과 |
| --- | --- |
| `10 / 0` (정수) | **ArithmeticException** (실행 중 에러) |
| `10.0 / 0` (실수) | `Infinity` |
| `10 % 0` (정수) | ArithmeticException |

### 나머지 연산 `%`

- 결과의 **부호는 왼쪽 피연산자**를 따른다.

```java
 10 %  3   // 1
-10 %  3   // -1
 10 % -3   // 1
```

### 오버플로우

```java
int max = Integer.MAX_VALUE;   // 2147483647
int n = max + 1;               // -2147483648 (에러 없이 최솟값으로 넘어감)

long l = 1_000_000 * 1_000_000;    // 오버플로우: int 끼리 곱한 뒤 long 에 저장
long m = 1_000_000L * 1_000_000;   // 1000000000000 (L 을 붙여 long 연산)
```

### 문자 연산

```java
char c1 = 'A';
int  n  = c1 + 1;          // 66
char c2 = (char)(c1 + 1);  // 'B'

char c3 = 'a' + 1;         // OK: 리터럴끼리 연산은 컴파일 때 계산된다
char c4 = c1 + 1;          // 에러: 변수가 있으면 int 로 계산됨
```

### 문자열 결합 `+`

- 피연산자가 **모두 숫자**면 덧셈, **한쪽이라도 String** 이면 다른 쪽을 문자열로 바꿔 **결합**한다.
- 왼쪽에서 오른쪽으로 계산되므로 순서에 따라 결과가 다르다.

```java
"" + 7 + 7     // "77"
7 + 7 + ""     // "14"
"A" + 1 + 2    // "A12"
1 + 2 + "A"    // "3A"
```

## 증감 연산자

| 형태 | 동작 |
| --- | --- |
| `++i` (전위) | 값을 **먼저 증가**시킨 뒤 사용 |
| `i++` (후위) | 값을 **먼저 사용**한 뒤 증가 |

```java
int i = 5;
int a = ++i;   // i = 6, a = 6
int b = i++;   // b = 6, i = 7
```

## 비교 연산자

```java
10 == 10.0       // true  (int 가 double 로 변환된 뒤 비교)
'A' == 65        // true
0.1 == 0.1f      // false (float 은 정밀도가 낮아 값이 미세하게 다름)
```

### `==` vs `equals()` (문자열 비교)

- `==` 는 **주소(같은 객체인지)**를 비교한다. 문자열 **내용** 비교는 **`equals()`** 를 쓴다.

```java
String s1 = "Java";
String s2 = new String("Java");

s1 == s2          // false (다른 객체)
s1.equals(s2)     // true  (내용이 같음)
```

---

## 논리 연산자

| 연산자 | 의미 |
| --- | --- |
| `&&` | AND. 둘 다 true 일 때 true |
| `\|\|` | OR. 하나라도 true 면 true |
| `!` | NOT |

### 단락 평가 (Short Circuit)

- `&&` 는 왼쪽이 **false** 면, `||` 는 왼쪽이 **true** 면 **오른쪽을 계산하지 않는다.**

```java
if (str != null && str.length() > 0) { ... }   // str 이 null 이면 length() 를 호출하지 않아 안전
```

- `&`, `|` 를 boolean 에 쓰면 **양쪽을 모두** 계산한다 (단락 평가 X).

---

## 삼항 연산자

```java
int abs = (x >= 0) ? x : -x;   // 조건 ? 참일 때 값 : 거짓일 때 값
```

## 복합 대입 연산자

```java
i += 3;    // i = i + 3

byte b = 10;
b = b + 5;   // 에러: b + 5 는 int
b += 5;      // OK: 복합 대입은 자동으로 (byte) 형변환이 포함됨
```

# 3. 조건문

## if

```java
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'C';
}
```

- 조건식은 반드시 **boolean** 이어야 한다. (`if (1)` 처럼 정수는 C와 달리 불가)
- 위에서부터 검사해서 **처음 true 인 블록 하나만** 실행한다.

---

## switch

### 기존 switch 문

```java
switch (month) {
    case 3: case 4: case 5:
        season = "봄";
        break;              // break 가 없으면 아래 case 까지 계속 실행 (fall-through)
    case 6: case 7: case 8:
        season = "여름";
        break;
    default:
        season = "그 외";
}
```

- 조건식 결과: **정수(int 이하), char, String, enum** 가능. `long`, 실수, boolean **불가**.
- case 값: **상수(리터럴, final 상수)** 만 가능, **중복 불가**.

### switch 표현식 (Java 14+)

```java
String season = switch (month) {
    case 3, 4, 5  -> "봄";
    case 6, 7, 8  -> "여름";
    default       -> {
        String s = "그 외";
        yield s;            // 블록에서 값을 돌려줄 때 yield
    }
};
```

- `->` 를 쓰면 **break 가 필요 없고 fall-through 가 없다.**
- 값을 반환할 수 있어 변수에 바로 대입한다.

### 패턴 매칭 switch (Java 21)

```java
String desc = switch (obj) {
    case Integer i when i > 0 -> "양수 " + i;
    case Integer i            -> "정수 " + i;
    case String s             -> "문자열 " + s;
    case null                 -> "null";
    default                   -> "기타";
};
```

- 타입으로 분기하고, 그 타입의 변수로 바로 꺼내 쓴다. `when` 으로 조건 추가.

# 4. 반복문

## for

```java
for (int i = 0; i < 5; i++) {      // 초기화; 조건식; 증감식
    System.out.println(i);
}

for (;;) { ... }                    // 조건식 생략 = 무한 반복
```

## 향상된 for (for-each)

```java
int[] arr = {10, 20, 30};
for (int n : arr) {
    System.out.println(n);
}
```

- 배열·컬렉션을 **읽기만** 할 때 쓴다. 인덱스가 필요하거나 요소를 바꿀 때는 일반 for.

## while / do-while

```java
while (i < 5) {       // 조건이 false 면 한 번도 실행 안 함
    i++;
}

do {                  // 조건과 상관없이 최소 1번은 실행
    input = read();
} while (input != 0); // 끝에 세미콜론
```

## break / continue / 이름 붙은 반복문

| 키워드 | 동작 |
| --- | --- |
| `break` | 가장 가까운 반복문을 **빠져나감** |
| `continue` | 이번 반복의 나머지를 건너뛰고 **다음 반복**으로 |

```java
outer:                               // 반복문에 이름 붙이기
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) continue outer;  // 바깥 반복의 다음 회차로
        if (i == 2) break outer;     // 바깥 반복까지 한 번에 탈출
    }
}
```

# 5. 배열

## 배열이란?

**같은 타입**의 여러 변수를 **하나의 묶음**으로 다루는 것이다.

```text
int[] score = new int[5];

score ──▶ ┌────┬────┬────┬────┬────┐
 (주소)   │ 0  │ 0  │ 0  │ 0  │ 0  │
          └────┴────┴────┴────┴────┘
 index      0    1    2    3    4        length = 5
```

- 배열 변수는 **참조형**이다. 실제 배열이 아니라 **배열의 주소**를 저장한다.
- 인덱스는 **0 ~ length-1**. 범위를 벗어나면 **ArrayIndexOutOfBoundsException**.

---

## 선언, 생성, 초기화

```java
int[] score;                 // 선언 (int score[] 도 가능하지만 int[] 권장)
score = new int[5];          // 생성: 길이 5, 기본값으로 채워짐

int[] a = new int[]{1, 2, 3};
int[] b = {1, 2, 3};         // 선언과 동시에 할 때만 new int[] 생략 가능

int[] c;
c = {1, 2, 3};               // 에러: 따로 대입할 때는 new int[] 필요
c = new int[]{1, 2, 3};      // OK
```

### 생성 시 기본값

| 타입 | 기본값 |
| --- | --- |
| `int`, `long`, `byte`, `short` | `0` |
| `double`, `float` | `0.0` |
| `boolean` | `false` |
| `char` | `'\u0000'` |
| 참조형 (String 등) | `null` |

---

## 배열의 길이

- `배열.length` 로 얻는다. **메서드가 아니라 속성** (`length()` X). String 은 `length()` 메서드.
- 한 번 만든 배열은 **길이를 바꿀 수 없다.** 더 큰 배열을 새로 만들어 복사해야 한다.

```java
int[] arr = {1, 2, 3};
int[] bigger = new int[arr.length * 2];
System.arraycopy(arr, 0, bigger, 0, arr.length);   // 원본, 시작, 대상, 시작, 개수

int[] copy = Arrays.copyOf(arr, 6);                 // 더 간단한 방법
```

---

## 배열은 참조형

```java
int[] a = {1, 2, 3};
int[] b = a;          // 배열이 복사되는 게 아니라 주소가 복사됨
b[0] = 100;
System.out.println(a[0]);   // 100 (a 와 b 가 같은 배열을 가리킴)
```

```text
a ──┐
    ├──▶ [100, 2, 3]
b ──┘
```

- 독립된 복사본이 필요하면 `Arrays.copyOf()` 또는 `arr.clone()`.

---

## Arrays 유틸리티

```java
int[] arr = {3, 1, 2};

System.out.println(arr);                   // [I@1b6d3586 (주소처럼 보이는 값)
System.out.println(Arrays.toString(arr));  // [3, 1, 2]
Arrays.sort(arr);                          // [1, 2, 3]
Arrays.equals(arr, new int[]{1, 2, 3});    // true (내용 비교. == 는 주소 비교)
Arrays.fill(arr, 0);                       // [0, 0, 0]
```

## 2차원 배열

```java
int[][] score = new int[3][2];   // 3행 2열

int[][] arr = {
    {1, 2},
    {3, 4},
    {5, 6}
};

arr.length       // 3 (행 개수)
arr[0].length    // 2 (0번 행의 열 개수)
```

### 가변 배열

- 행마다 **열의 길이를 다르게** 만들 수 있다.

```java
int[][] jagged = new int[3][];   // 열 길이는 나중에
jagged[0] = new int[2];
jagged[1] = new int[4];
jagged[2] = new int[1];
```

# 핵심 정리

- 기본형 8개는 **실제 값**, 나머지(String, 배열, 객체)는 **주소**를 저장한다.
- 정수 기본 `int`, 실수 기본 `double`. `long` 은 `L`, `float` 은 `f` 접미사 필수.
- 작은 타입 → 큰 타입은 자동 형변환, 반대는 `(타입)` 명시 + 값 손실 주의.
- `byte + byte` 의 결과는 `int`. 정수 / 정수는 소수점 버림.
- 오버플로우는 **에러 없이** 값이 넘어간다.
- 문자열 내용 비교는 `==` 가 아니라 **`equals()`**.
- `&&`, `||` 는 단락 평가.
- switch: `long`·실수 불가. Java 14+ `->` 는 break 불필요. Java 21 패턴 매칭.
- 배열은 참조형. `b = a` 는 같은 배열 공유. 길이는 `length` (속성), 변경 불가.
